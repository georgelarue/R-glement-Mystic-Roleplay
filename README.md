# 📜 Règlement Mystic Roleplay

### 🤝 1. Respect
- Respectez les joueurs et le staff.
- Les insultes discriminatoires, le harcèlement et la triche sont interdits.
- Le métagaming, le freekill et le powergaming sont interdits.
- Respectez le FearRP et la New Life Rule.

### 🎭 2. Roleplay
- Jouez votre personnage de manière réaliste.
- Ne profitez pas des bugs ou des mécaniques pour obtenir un avantage.
- Ne quittez pas une action pour éviter ses conséquences.

### 🏠 3. Constructions
- Les propblocks et constructions abusives sont interdits.
- Ne bloquez pas les passages avec des props ou des véhicules.
- Les constructions doivent rester réalistes.

### 🔫 4. Actions illégales
- Toute action doit avoir une raison RP valable.
- Respectez les limites de joueurs et les règles de négociation.
- Les prises d'otages et les braquages doivent respecter le règlement.

### 🚓 5. Métiers
- Les métiers gouvernementaux ne peuvent pas être corrompus.
- Ne bloquez pas les soins des médecins.
- Ne monopolisez pas les propriétés ou les services.

### 💬 6. Communication
- Utilisez les canaux pour leur fonction.
- Les nuisances sonores et les tickets abusifs sont interdits.
- Les décisions du staff doivent être respectées.

### ⚖️ 7. Sanctions
Tout manquement peut entraîner un avertissement, un bannissement temporaire ou définitif selon la gravité.

**En rejoignant Mystic RolePlay, vous acceptez ce règlement.**
